# User Manual

# TTU Industrial Attachment System (TTU-IAS)

---

# 1. Introduction

The TTU Industrial Attachment System (TTU-IAS) is a web-based platform developed to manage the industrial attachment process at Takoradi Technical University.

The system provides different dashboards for Students, Companies, Industry Supervisors, Academic Supervisors, Liaison Officers, and Administrators.

Each user has access only to features relevant to their role.

---

# 2. Logging In

1. Open the system using the provided website address.
2. Enter your Login ID.
3. Enter your Password.
4. Click **Login**.

After successful authentication, you will be redirected to your dashboard.

---

# 3. Student Guide

After logging in, students can:

## Dashboard

- View internship progress
- View internship journey
- View announcements (if available)

---

## Placement Request

Students can:

- Select an existing company
- Register a new company
- Submit a placement request
- Track approval status

---

## Weekly Logbook

Students can:

- Submit weekly activities
- Edit logbook entries before certification
- View certification status

---

## Reports

Students can submit:

- Weekly Reports
- Monthly Reports
- Final Internship Report

Students can also:

- View supervisor remarks
- Monitor approval status

---

## Results

Students can:

- View completed assessments
- View overall scores
- Track assessment progress

---

# 4. Company Guide

Companies can:

- View assigned students
- Assign Industry Supervisors
- Monitor internship activities

---

# 5. Industry Supervisor Guide

Industry Supervisors can:

- View assigned students
- Review submitted reports
- Approve or reject reports
- Add remarks
- Certify weekly logbooks
- Complete student assessments
- View assessment results

---

# 6. Academic Supervisor Guide

Academic Supervisors can:

- View assigned students
- Review reports
- Review weekly logbooks
- Complete academic assessments
- View assessment results

---

# 7. Liaison Officer Guide

Liaison Officers can:

- Review placement requests
- Approve placement requests
- Reject placement requests
- View placement records
- Monitor internship progress

---

# 8. Administrator Guide

Administrators can:

- Create users
- Manage users
- Activate or deactivate accounts
- Manage students
- Manage supervisors
- Manage companies
- Monitor the entire system

---

# 9. Password Management

Users should:

- Keep passwords confidential.
- Change passwords when required.
- Contact the Administrator if login problems occur.

---

# 10. Logout

To securely exit the system:

1. Click the profile menu.
2. Select **Logout**.

Always log out after using the system on shared computers.

---

# 11. Best Practices

- Use a modern web browser.
- Do not share login credentials.
- Submit reports before deadlines.
- Ensure placement information is accurate.
- Review all information before submission.

---

# 12. Troubleshooting

## Unable to Login

Verify:

- Login ID
- Password
- Internet connection

---

## Unable to Submit Reports

Ensure all required fields have been completed.

---

## Unable to View Results

Results become available only after supervisors complete assessments.

---

# 13. Support

For assistance, contact the System Administrator or the TTU Liaison Office.
