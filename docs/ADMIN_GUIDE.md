# Administrator Guide

# TTU Industrial Attachment System (TTU-IAS)

---

# 1. Introduction

This guide provides instructions for managing the TTU Industrial Attachment System (TTU-IAS). It is intended for System Administrators responsible for maintaining users, monitoring system activities, and ensuring the smooth operation of the platform.

---

# 2. Administrator Responsibilities

The Administrator is responsible for:

- Creating user accounts
- Managing user roles
- Activating and deactivating accounts
- Monitoring internship activities
- Maintaining system security
- Supporting users when necessary

---

# 3. Logging In

1. Open the TTU-IAS website.
2. Enter your Login ID.
3. Enter your Password.
4. Click **Login**.

After successful authentication, the Administrator Dashboard will be displayed.

---

# 4. Administrator Dashboard

The dashboard provides an overview of the system, including quick access to:

- User Management
- Student Management
- Company Management
- Academic Supervisors
- Industry Supervisors
- Liaison Officers
- System Statistics

---

# 5. User Management

Administrators can:

- Create new users
- View all registered users
- Edit user information
- Activate user accounts
- Deactivate user accounts
- Assign user roles

Supported roles include:

- Administrator
- Liaison Officer
- Student
- Company
- Academic Supervisor
- Industry Supervisor

---

# 6. Student Management

Administrators can:

- View registered students
- Monitor internship records
- Verify student information

---

# 7. Company Management

Administrators can:

- View registered companies
- Monitor company information
- Verify company details

---

# 8. Supervisor Management

Administrators can manage:

## Academic Supervisors

- View supervisors
- Monitor assigned students

## Industry Supervisors

- View supervisors
- Monitor assigned students

---

# 9. Placement Monitoring

Administrators can monitor:

- Placement requests
- Approved placements
- Rejected placements
- Internship assignments

Although placement approvals are handled by the Liaison Officer, the Administrator has visibility into all placement activities.

---

# 10. Report Monitoring

Administrators can monitor:

- Weekly Reports
- Monthly Reports
- Final Reports

This helps ensure that internship activities are progressing as expected.

---

# 11. Assessment Monitoring

Administrators can view:

- Assessment progress
- Completed assessments
- Outstanding assessments
- Published results

---

# 12. Security Best Practices

Administrators should:

- Protect administrator credentials.
- Avoid sharing accounts.
- Deactivate unused accounts.
- Regularly review user access.
- Ensure only authorized users have administrator privileges.

---

# 13. System Maintenance

Regular maintenance tasks include:

- Monitoring application performance
- Checking database connectivity
- Reviewing system logs
- Updating dependencies
- Applying security updates
- Creating database backups

---

# 14. Troubleshooting

## User Cannot Login

Verify:

- Login ID
- Password
- Account status

---

## Missing Data

Confirm database connectivity and verify that migrations have been successfully applied.

---

## Slow Performance

Check:

- Server resources
- Database performance
- Network connectivity

---

# 15. Support

For technical issues beyond routine administration, contact the development team.
